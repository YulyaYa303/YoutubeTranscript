# Видео словами

Веб-приложение получает полный транскрипт видео с YouTube через Supadata и показывает над ним краткое содержание на русском, подготовленное моделью OpenRouter `openrouter/free`.

## Локальный запуск

Нужен Node.js 24. При наличии ключей скопируйте `.env.example` в `.env` и заполните значения. Запустите `npm run dev` и откройте `http://localhost:3000`. Сторонних зависимостей нет.

## Vercel

Импортируйте репозиторий в Vercel с настройкой Framework Preset **Other**. Добавьте `SUPADATA_API_KEY` и `OPENROUTER_API_KEY` в **Settings → Environment Variables** для Production и запустите деплой. Статические файлы лежат в `public`, серверная функция — в `api/transcript.js`. Ключи читает только функция.

Для проверки вставьте `https://www.youtube.com/watch?v=qg4D7NFtTeI`. Ожидается краткое содержание на русском над транскриптом. Если OpenRouter недоступен, приложение показывает полный транскрипт и сообщение в разделе краткого содержания.
